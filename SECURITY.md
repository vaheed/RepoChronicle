# Security Policy

## Supported versions

Security fixes are currently accepted for the latest default branch because RepoChronicle is an early foundation scaffold.

## Reporting a vulnerability

Please do not post credentials, private repository URLs, exploit details, or sensitive production data in a public issue. Use GitHub's private vulnerability reporting for this repository where available. Include:
- affected component and version/commit;
- impact and prerequisites;
- minimal reproduction using synthetic data;
- suggested mitigation, if known.

## Secrets and private data

Never include live secrets or private code/chat exports in issues, fixtures, screenshots, tests, or logs. Rotate any credential that has been committed or exposed. See `docs/SECURITY_MODEL.md` for system controls and response expectations.
